# <p align="center">mixEm — Color Wheel & Palette Builder</p>

<p align="center">
  <b>mixEm</b> is a fast, lightweight Progressive Web App (PWA) designed to pick colors, generate harmonies, and export palettes on the go. Works directly in your browser with zero build steps or server dependencies.
</p>

<p align="center">
  <a href="https://yunicorn-dev.github.io/mixem"><b> Launch App</b></a>
</p>

---

### Key Features

* **Color Wheel:** Touch-friendly HTML5 Canvas for smooth Hue and Saturation adjustments.
* **7 Color Harmonies:** Monochromatic, Analogous, Complementary, Split Complementary, Triadic, Square, and Rectangle.
* **Live Conversions:** Instant synchronization across HEX, RGB, and HSB formats.
* **Export Options:** Download palettes in **JSON**, **PNG**, or **.ASE** (Adobe Swatch Exchange) format, or copy hex codes with a single click.
* **Palette Storage:** Save, manage, and export multiple color sets during your session.

---

### Compatibility & PWA Installation

Runs smoothly on virtually any modern web browser across desktop, laptops, tablets, and smartphones (iOS & Android). For maximum touch responsiveness and stability on mobile devices, **Google Chrome** or **Safari** is recommended.

#### Add to Home Screen (Mobile)
* **iOS / iPadOS (Safari):** Tap **Share** → **Add to Home Screen**.
* **Android (Chrome):** Tap the **Menu (⋮)** → **Add to Home Screen / Install App**.
